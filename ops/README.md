# Operations Playbooks

This directory will capture operational resources for the Ordering Intelligence platform, including:

- Incident response runbooks.
- Monitoring and alert configuration references.
- On-call procedures and escalation policies.
- Post-incident review templates.

Refer to `docs/ai-ordering-platform-spec.md` Section 17.2 for the initial runbook checklist to populate here.

Current contents:

- `runbooks/` – AI conversation quality review, telephony outage response.
- `runbooks/incident-response.md` – general incident handling playbook.
- `monitoring/` – dashboard and alert guideline with notification channel configuration.
